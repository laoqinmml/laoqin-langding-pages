AI Agent 使用方式：不要一次性把整个模板丢给用户。按阶段询问，已有答案就填入，缺少时给默认建议。

- 品牌名：
- 目标国家：
- 目标语言：
- 行业：
- 主要产品/服务类型：
- 核心卖点：
- 目标客户：

建议提问：

> 先告诉我：公司名、品牌名、目标国家、目标语言、行业、主要产品/服务分别是什么？如果你没有想好品牌主色和页面风格，我可以先给默认建议。

## 阶段 2：视觉与品牌

- Logo：已有 / 暂无 / 需要文字 Logo
- 主色：
- 参考网站：
- 风格模板（可选）：从 https://styles.refero.design/ 下载的 DESIGN.md
- 参考截图（可选）：喜欢的网站整页截图（桌面 + 手机），并圈出最想要的那一块
- 喜欢的风格：简洁 / 科技 / 工厂实力 / 高端品牌 / 电商转化 / 其他

建议提问：

> 你有 Logo 和参考网站吗？想要什么风格有三条路选一条：① 去 styles.refero.design 挑一个，把 DESIGN.md 发我；② 直接发我一张你喜欢的网站截图（整页、桌面和手机各一张，圈出你最想要的那块），我照着那个结构与感觉做；③ 都懒得弄，我按你的行业给默认配色，或者先出几个方向给你选。

## 阶段 4：页面功能

固定规则：

- 首页：必须有，默认选中。
- 产品页：可选；如果选择，必须自动创建产品分类页。
- 博客页：可选；如果选择，必须自动创建博客分类页。
- 案例页：可选。
- FAQ：可选。
- 资料下载页：可选，用于 PDF 产品目录、规格书、报价表模板、采购清单、案例 PDF、ZIP 资料包等静态文件。

建议提问：

> 你需要哪些页面？首页默认必须有。是否需要产品页、博客页、案例页、FAQ、资料下载页？如果要产品页，我会自动加产品分类页；如果要博客页，我会自动加博客分类页。
